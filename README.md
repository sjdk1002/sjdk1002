# 강한호

**모바일 앱 개발자 · Swift/UIKit · React/TypeScript · Capacitor**

카찹을 공동창업하고 초기 앱 개발부터 출시 후 기능 개선과 유지보수까지 맡았습니다.
앱 화면을 만드는 일과 함께, SDK·API·배포를 연결하고 운영 중 생기는 문제를 고치는 일을 해왔습니다.

## 주로 해온 일

- **iOS 앱 개발** — Swift와 UIKit으로 지도·검색, 계정·인증, 카풀·채팅, 결제 기능을 개발하고 유지보수했습니다.
- **React 웹과 Capacitor 앱** — 웹과 iOS·Android 앱 전반을 만들고, 권한·푸시·화면 이동·파일 공유 같은 기기 기능을 연결했습니다.
- **관리자 웹** — React와 TypeScript로 충전소·예약·결제 화면을 만들고, 데이터 조회와 캐시·요청 상태를 관리했습니다.
- **서비스 연동과 운영** — H2CARE Flutter 앱 개발·유지보수와 함께 API, 차량 데이터, CCTV 영상 연동도 다뤘습니다.

## 기술

| 주로 쓰는 기술 | 프로젝트에서 함께 다룬 기술 |
| --- | --- |
| Swift, UIKit | Flutter, Dart, Riverpod |
| React, TypeScript, Capacitor | Android Java, Spring Boot, Node.js |
